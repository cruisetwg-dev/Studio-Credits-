# Studio-Credits-

A classroom progress tracker for the Pro Tools Foundations course.

## How to use

Open `studio-credits.html` in a web browser. No install or server is needed.

The app has six tabs:

- **Board** – class progress at a glance
- **Award** – give students credits for activities
- **Growth** – progress over time
- **Roster & Badges** – add students and see their badges
- **Log** – history of every award
- **Print cards** – printable level and badge cards

Use the **Projector** button for a full-screen view to show the class.

Data is saved in your browser's local storage, so it stays on the computer and browser you used.
